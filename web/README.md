# 공연 스케줄 (뮤킷 대체용 개인 서비스)

연극·뮤지컬 공연 일정과 **회차별 캐스팅**을 한곳에서 보는 개인용 웹앱.
서비스 종료된 [뮤킷](https://myukit.com)의 핵심 기능을 직접 쓰려고 다시 만든 것.

## 데이터 출처

- **공연 마스터 데이터**: KOPIS(공연예술통합전산망) 오픈API — 공연명/기간/장소/포스터/가격/출연진 명단/공연시간 패턴
- **회차별 캐스팅**: KOPIS가 제공하지 않는 정보라, 예매처 캘린더를 붙여넣거나 캡처를 올리면 Claude가 회차별 캐스팅으로 변환해 저장

> 공연 정보 출처: (재)예술경영지원센터 공연예술통합전산망(www.kopis.or.kr)

## 시작하기

### 1. 인증키 준비

```bash
cp .env.local.example .env.local
```

`.env.local`에 두 개를 채운다.

| 키 | 발급처 | 용도 |
|---|---|---|
| `KOPIS_API_KEY` | https://www.kopis.or.kr/por/cs/openapi/openApiUseSend.do | 공연 목록·상세 |
| `ANTHROPIC_API_KEY` | https://console.anthropic.com/settings/keys | 캐스팅 자동 추출 |

KOPIS 인증키는 **PC에서만 발급**되고 1인 1개다. 발급 후 메일로 온다.

### 2. 실행

```bash
npm run dev      # http://localhost:3000
```

같은 와이파이의 휴대폰에서 보려면 터미널에 찍히는 `Network:` 주소로 접속.

## 사용 흐름

1. **전체 공연 → "KOPIS 동기화"** — 앞으로 3개월치 연극·뮤지컬 목록을 가져온다.
2. **공연 상세 → "KOPIS 상세 불러오기"** — 출연진·가격·공연시간을 가져오고,
   요일 패턴(`화~금(20:00), 토(15:00,19:00)`)을 실제 날짜별 **회차 달력**으로 펼친다.
3. **"캐스팅 등록"** — 예매처 캐스팅표를 붙여넣거나 캡처를 올리면 회차별 캐스팅이 채워진다.
4. **"추적하기"** — 자주 보는 공연만 따로 모아둔다.
5. 배우 이름을 누르면 **애배 등록** → 애배 달력에 그 배우 회차만 모인다.

## 화면

| 경로 | 설명 |
|---|---|
| `/` | 오늘의 공연 — 날짜별 회차 + 그날 캐스팅 (애배는 빨갛게) |
| `/shows` | 전체 공연 목록, 상태/장르 필터 |
| `/shows/[id]` | 공연 상세 + **회차별 캐스팅 달력**(달력/목록 전환) |
| `/actors/[name]` | 배우별 출연 회차 |
| `/my/actors` | 애배 달력 |
| `/my/calendar` | 내 관람 일정 |

## 구조

```
src/
  lib/
    db.ts        SQLite 스키마 (node:sqlite 내장 모듈, 네이티브 빌드 없음)
    kopis.ts     KOPIS 오픈API 클라이언트 (XML → JSON)
    schedule.ts  KOPIS 요일 패턴 → 실제 회차 목록으로 펼치기
    extract.ts   예매처 텍스트/이미지 → 회차별 캐스팅 (Claude)
    queries.ts   DB 조회·저장
  app/
    api/         sync, shows/[id], shows/[id]/extract, favorites
    …            화면
data/app.db      로컬 데이터 (git 제외)
```

## 알아둘 점

- **회차는 "예상"이다.** KOPIS는 요일 패턴만 주고 실제 공연 일정표는 주지 않는다.
  휴관일이나 비정기 회차는 반영되지 않으니, 실제 예매 전에는 예매처에서 다시 확인할 것.
- **캐스팅 추출은 완벽하지 않다.** 결과에 warnings가 뜨면 그 부분은 직접 확인하는 게 좋다.
- 데이터는 전부 `data/app.db` 한 파일에 들어간다. 백업은 이 파일만 복사하면 된다.
