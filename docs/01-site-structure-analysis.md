# 공연 스케줄/출연진 정보 수집 대상 사이트 1차 구조 분석

- 분석일: 2026-08-31
- 도구: Playwright MCP (실브라우저 렌더링) + WebSearch/WebFetch
- 목적: 공연(연극/뮤지컬/콘서트 등) 스케줄·출연진 정보를 정리해서 보여주는 웹사이트를 만들기 위한 데이터 소스 후보 조사
- 스크린샷: `docs/screenshots/`
- 원문 자료: `docs/kopis-openapi-guide.pdf` (원본), `docs/kopis-openapi-guide.txt` (텍스트 추출본)

## 요약 (TL;DR)

| 사이트 | 성격 | 공식 API | 출연진(캐스팅) 데이터 | 자동화 접근 시 리스크 |
|---|---|---|---|---|
| **KOPIS** (kopis.or.kr) | 정부 공인 공연 통합 DB | **있음** (무료, 인증키 신청) | **있음** (`prfcast`, `prfcrew` 필드 확인) | 낮음 (공식 API 사용 시) |
| **연뮤덕** (yeonmuduck.com) | 민간 팬 사이트 (KOPIS 기반 큐레이션 서비스) | 없음 (본인들도 KOPIS 원천 데이터 사용) | 있음 (KOPIS 데이터를 가공해 표시) | 이 프로젝트의 사실상 **직접 경쟁자** — 벤치마킹 대상 |
| **NOL 티켓(인터파크)** (nol.interpark.com) | 민간 티켓 예매 플랫폼 | 없음, 내부 전용 API만 존재 | 상세페이지에는 있을 가능성 높으나 미검증 | 중간 (ToS상 크롤링 금지 소지, 광고/트래킹 스크립트 과다) |
| **예스24 티켓** (ticket.yes24.com) | 민간 티켓 예매 플랫폼 | 없음 | 미검증 (상세페이지 미조사) | 중간 |
| **티켓링크** (ticketlink.co.kr) | 민간 티켓 예매 플랫폼 | 없음 | 미검증 | **높음** — 자동화 접속 시 즉시 "비정상 활동 감지, 계정 차단 가능" 경고 발생 (아래 상세 참고) |
| **멜론티켓** (ticket.melon.com) | 민간 티켓 예매 플랫폼 | 없음 | 미검증 | 중간 |

**결론(1차)**: 서비스의 데이터 백본은 **KOPIS 오픈API**로 가는 것이 사실상 유일하게 합법적이고 안정적인 선택지다. 이미 **연뮤덕(yeonmuduck.com)이 정확히 이 방식(KOPIS 데이터 기반 뮤지컬/연극 정보 큐레이션)으로 서비스 중**이므로, 차별화 포인트를 먼저 정하고 들어가야 한다. 민간 티켓사 사이트는 데이터 커버리지(콘서트/대중음악 등) 보완용으로만 검토하되, 공식 제휴 없는 크롤링은 리스크가 있다(특히 티켓링크는 봇 탐지가 즉시 작동함을 실측 확인).

## 1. KOPIS (공연예술통합전산망) — kopis.or.kr

### 1.1 사이트 구조
- 메인 페이지에 **DB제공** 섹션으로 6종 DB 노출: 공연DB / 공연시설DB / 기획·제작사DB / 수상작DB / 축제DB / 원·창작자DB
- 공연통계(공연건수/횟수/티켓판매수/판매액), 예매통계(예매상황판) 대시보드 제공 — 일간/주간/월간 필터
- 장르 필터: 연극, 뮤지컬, 서양음악(클래식), 한국음악(국악), 대중음악, 무용, 대중무용, 서커스/마술, 복합, 아동, 대학로, 내한, 배리어프리, 축제
- 상단 GNB에 "MY통계로그인" — 통계 기능은 로그인 필요, 단순 조회/API는 불필요

### 1.2 오픈API (`/por/cs/openapi/openApiInfo.do`)
- 메뉴 구성: OPEN API 소개 / API 항목확인 / **인증키 발급신청** / API FAQ
- 인증키는 **1인당 1개**, PC에서만 발급 가능, 타인 양도·공유 불가
- 이용 시 반드시 출처 명시 필요 (`출처: (재)예술경영지원센터 공연예술통합전산망(www.kopis.or.kr)`) — 미표기 시 서비스 중단될 수 있음
- 쿼리 호출 한도 있음 (초과 시 서비스 중지) — 정확한 한도는 개발가이드 참고
- **개발자가이드 PDF 실제 다운로드 및 텍스트 추출 완료** (`kopis-openapi-guide.pdf`, 32페이지)

### 1.3 공연상세 조회 API 실제 스펙 (PDF 원문 확인)
```
서비스명: 공연상세 조회 서비스 (pblprfrDetailService)
URL: http://www.kopis.or.kr/openApi/restful/pblprfr/{공연ID}?service={인증키}
버전: 5.0 (2026.04.23 최신 배포)
응답 포맷: XML
```

주요 응답 필드 (직접 확인):
| 필드명 | 설명 |
|---|---|
| `prfnm` | 공연명 |
| `prfpdfrom` / `prfpdto` | 공연 시작일/종료일 |
| **`prfcast`** | **출연진** |
| **`prfcrew`** | **제작진** |
| `prfruntime` | 공연 러닝타임 |
| `prfage` | 관람 연령 |
| `entrpsnm` / `entrpsnmP` / `entrpsnmA` / `entrpsnmH` / `entrpsnmS` | 제작사/기획사/주최/주관/예매처 |
| `pcseguidance` | 가격 정보 |
| `fcltynm` | 공연시설명 |
| `sty` | 줄거리/시놉시스 |
| `styurls` | 소개 이미지 URL 목록 |
| `prfstate` | 요일별 공연 시간 안내 |
| `dtguidance` | 공연시간 관련 추가 안내 |
| `relates` (`relatenm`/`relateurl`) | 관련 링크(예매처 등) |
| `genrenm`, `area`, `openrun`, `visit`(내한), `child`, `daehakro`, `festival` | 분류/플래그성 필드 |

> **핵심 발견**: KOPIS 오픈API는 **출연진(prfcast)과 제작진(prfcrew)을 공식 필드로 제공**한다. 이전 웹서치 단계에서는 확인이 안 됐던 부분인데, 이번에 PDF 원문에서 직접 확인했다. 다만 이 필드가 얼마나 자주/정확히 채워지는지(자유 텍스트 필드라 파싱 난이도 있음, 예: "차인표, 오만석, ...")는 실제 API 호출 테스트로 별도 검증 필요.

### 1.4 참고
- 홈페이지 자체는 구형 정부/공공기관 UI(jQuery 기반, 반응형 아님)이며 사람이 보는 용도로는 불편함 — 이 프로젝트는 **API 소비자**로만 KOPIS를 활용하는 게 맞다.

## 2. 연뮤덕 (yeonmuduck.com) — ⚠️ 직접 경쟁 서비스로 파악됨

### 2.1 개요
- Next.js 기반 (App Router, RSC 프리페치 트래픽 다수 관측: `?_rsc=...`)
- 홈 문구: **"연극과 뮤지컬, 흩어진 정보를 한곳에" / "공연 일정부터 캐스팅, 가격, 영상까지. 여러 사이트를 돌아다닐 필요 없습니다."**
- 푸터에 명시: **"데이터 출처: KOPIS (공연예술통합전산망)"** → 사용자가 만들고 싶어하는 서비스와 데이터 소스, 컨셉이 거의 동일

### 2.2 라우트 구조 (네트워크 로그로 확인)
- `/` — 홈 (이번 주 박스오피스, 곧 시작하는 공연)
- `/shows` — 전체 공연 목록 (쿼리: `?genre=GGGA&state=upcoming`, `?cast=배우명` 등 필터 지원)
- `/shows/{id}` — 공연 상세 (KOPIS의 `mt20id`로 추정되는 숫자 ID)
- `/rankings` — 박스오피스 랭킹 (뮤지컬 TOP5 / 연극 TOP5, 이번 주 기준)
- `/map` — 공연장 지도
- `/glossary` — 공연 용어사전 (초보 관객 대상 온보딩 콘텐츠)
- `/legal/terms-of-service.html`, `/legal/privacy-policy.html`

### 2.3 공연 상세 페이지 구성 (`/shows/43234` 실측)
1. 포스터 이미지 + 상태 배지(공연중/공연예정/공연완료) + 장르 + 지역 태그
2. 공연 기간 / 공연장명 / 주소 / 러닝타임 / 관람연령
3. **예매하기 버튼 그룹** — 관측된 예매처: 29CM, 나눔티켓, 네이버N예약, 놀유니버스(인터파크), 예스24, 카카오톡예약, 코스타(Coaster), 쿠팡 → **하나의 공연이 여러 예매처에 동시 등록되는 경우가 흔함**을 실증
4. 탭: 공연 정보 / 공연 소개 / 위치
5. 가격 정보 (좌석 등급별)
6. 공연 일정 (요일별 시간)
7. **출연진** — 배우 이름을 클릭하면 `/shows?cast=배우명`으로 이동, 해당 배우 출연작 필터링 (UX 아이디어로 참고할만함)
8. 제작진 / 제작사
9. 공연 소개 (이미지 + 더보기)
10. 이 작품의 다른 시즌·공연 (재공연/지방 투어 연결)
11. 이 공연장의 다른 공연 (같은 극장 다른 작품)
12. 위치 (카카오맵 연동)

### 2.4 시사점
- **경쟁 서비스가 이미 존재**하고, 데이터 소스·핵심 기능(캐스팅/가격/일정 통합, 다중 예매처 링크, 배우별 필터, 용어사전)까지 상당히 구체화되어 있음
- 사용자가 만들려는 서비스와 차별화 지점을 먼저 정해야 함 (예: 콘서트/대중음악 특화, 캐스팅 변경 알림, 특정 지역/소극장 특화, 팬 커뮤니티 기능 등) — 이건 구현 전에 논의 필요한 부분

## 3. 민간 티켓 플랫폼

### 3.1 NOL 티켓 (구 인터파크) — nol.interpark.com/ticket
- `tickets.interpark.com` 접속 시 `nol.interpark.com/ticket`으로 리다이렉트
- 공식 오픈API 없음. 내부 전용(비공개) REST 엔드포인트만 관측됨:
  - `/ticket/api/open-notice/main`
  - `/ticket/api/play-dic/main-gallery?category=MUSICAL&category=CONCERT&...`
  - `/header-api/newplatform/display/...`
- 위 엔드포인트는 **프론트엔드 내부용으로, 공식 문서화된 공개 API가 아님** — 구조 변경이 잦고 이용약관상 비인가 접근/수집 금지 소지가 있어 그대로 스크래핑 근거로 쓰기엔 리스크가 있음
- 페이지에 Google Ads, GA4, Branch, YouTube 등 광고/트래킹 스크립트가 매우 많아 실제 콘텐츠 대비 네트워크 노이즈가 큼

### 3.2 예스24 티켓 — ticket.yes24.com
- 메인 화면 스크린샷만 확보(`screenshots/yes24-main.png`), 상세 구조는 미조사
- 연뮤덕에서 예매처로 실제 연결되는 것으로 보아 뮤지컬/연극 커버리지는 확보된 것으로 보임

### 3.3 티켓링크 — ticketlink.co.kr ⚠️
- 접속 즉시(`/home` 로드 중) **경고 다이얼로그 발생**: `"시스템에서 비정상적인 활동이 감지되었습니다. 계속될 경우 계정이 차단될 수 있습니다. (ErrorCode:200)"`
- 즉, **자동화 브라우저 접근을 적극적으로 탐지**하고 있음이 실측으로 확인됨
- **권고**: 이 사이트는 크롤링/자동화 접근을 시도하지 말 것. 데이터가 필요하면 공식 제휴 문의만 고려

### 3.4 멜론티켓 — ticket.melon.com
- 메인 화면 스크린샷만 확보(`screenshots/melon-main.png`), 특이 경고나 봇 탐지는 관측되지 않음. 상세 구조는 미조사 (콘서트/대중음악 커버리지가 강점일 것으로 추정, 검증 필요)
